# Outreach Notes

## How to describe the project

Lead with the empirical question:

> Do multiple AI safety monitors actually provide complementary error detection, or do they share correlated blind spots?

Use standard AI safety terminology:

- monitor error correlation;
- unique catches;
- ensemble complementarity;
- rule-induced diversity;
- shared blind spots;
- benchmark provenance;
- fixed-FPR evaluation.

## What not to claim

Do not say:

- the project has already demonstrated monitor independence;
- the project has already improved AI safety;
- synthetic API smoke results are experimental findings;
- the extra refusal-forcing directory is known to have been intentionally excluded for a specific reason.

## Outreach order

First ask for methodological criticism.

Second, if the design seems worthwhile, ask about:

- replication;
- collaboration;
- inference access;
- API/compute credits;
- stronger external validation.

## Suggested status sentence

> The study is preregistered and analysis-ready, but the confirmatory benchmark experiment has not yet been run.
